## Local preview

Open `index.html` in a browser, or run a local development server from this folder.

## Deployment

This site is designed for GitHub Pages and the repository name `Naran121x/naran121x.github.io`.

In GitHub, open **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/(root)**, then save.

## Search visibility

The site includes:
- A descriptive page title and meta description
- Canonical URL
- Person/ProfilePage structured data
- `sitemap.xml`
- `robots.txt`

Search engines decide independently whether and when to index the site. Structured data does not guarantee a Google Knowledge Panel.
